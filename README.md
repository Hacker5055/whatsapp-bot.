# 🖤 Black X — بوت واتساب عربي

بوت لإدارة مجموعات واتساب مبني على مشروع [Knightbot-MD](https://github.com/mruniquehacker/Knightbot-MD)، مع هوية **Black X**، قائمة وأوامر ورسائل عربية، وتخزين دائم للجلسة على Heroku. حقوق المشروع الأصلي محفوظة؛ انظر [NOTICE.md](NOTICE.md).

> **ابدأ هنا:** [الدليل الكامل لربط رقم واتساب وتشغيل Black X على Heroku بالعربي](docs/HEROKU_AR.md).
>
> لم يتم ربط رقم واتساب أو نشر تطبيق Heroku لك تلقائيًا؛ الخطوات تتطلب حسابك ورقمك وصلاحية الوصول إليهما. لا ترسل كود الربط أو مفتاح الجلسة لأي شخص.

## المميزات

- أوامر عربية تبدأ بنقطة، مع بقاء الأوامر الإنجليزية الأصلية: `.اوامر`، `.سرعة`، `.ملصق`، `.منع_الروابط تشغيل`، `.ذكاء سؤالك`، `.وضع عام`.
- قائمة مساعدة عربية؛ رسائل الإدارة والتنبيهات وأخطاء الاستخدام بالعربي. الكلمات/العناوين القادمة من خدمات خارجية (زي الأغاني وبعض مخرجات صور وخدمات API) قد تبقى بلغتها الأصلية.
- ألعاب وأسئلة ونكت وحِكم وصراحة وجرأة بالعربي بدون الاعتماد على خدمات نص إنجليزية.
- نطق عربي افتراضيًا، والذكاء الاصطناعي يطلب ردًا عربيًا ويُترجم الرد غير العربي عند الإمكان؛ بعض الخدمات الخارجية غير مضمونة التوفر.
- الوضع الافتراضي **خاص** لتجنب الرد على الجميع بالخطأ. فعّل العام بـ `.وضع عام` من رقم المالك.
- جلسة WhatsApp Signal تُحفظ في PostgreSQL بعد تشفير AES-256-GCM، وإعدادات الحماية للمجموعات تحفظ أيضًا. تُمنع النسخ المزدوجة للجلسة بقفل قاعدة بيانات.
- `heroku.yml` + `Dockerfile` لتشغيل عامل `worker` بلا واجهة ويب أو طلبات ping وهمية.

## تشغيل محلي سريع

تحتاج Node.js **22**، npm 10+ وFFmpeg. استخدم رقم واتساب تملكه أو عندك إذن باستخدامه، ويفضل رقم منفصل للبوت.

```bash
git clone <رابط_مستودعك_بعد_رفع_تعديلات_Black_X> black-x
cd black-x
cp .env.example .env
# افتح .env واضبط OWNER_NUMBER=رقمك_الدولي_بدون_علامة_زائد
npm ci
npm run check
npm test
npm run pair -- 201012345678   # بدّل المثال برقمك الدولي الحقيقي، بدون +
npm start
```

بدل كود الربط، اترك `PAIRING_NUMBER` فارغًا ونفذ `npm run pair` بدون رقم: سيظهر QR في الطرفية، ثم امسحه من **واتساب ← الإعدادات ← الأجهزة المرتبطة ← ربط جهاز**. للكود اختر من نفس شاشة واتساب **الربط برقم الهاتف** وأدخل الكود الظاهر في الطرفية. على نفس الهاتف الذي تريد ربطه، افتح قائمة الأجهزة المرتبطة؛ بعض واجهات واتساب تعرض خيار الكود في شاشة الربط للجهاز الثانوي. لا تشغّل `npm run pair` و`npm start` معًا على نفس الجلسة.

في التشغيل المحلي تُحفظ الجلسة في `session/` (ملف محلي **سري وغير مرفوع إلى Git**). على Heroku تحتاج PostgreSQL ومفتاح التشفير قبل الربط لأن القرص مؤقت. التفاصيل في [الدليل](docs/HEROKU_AR.md).

## أوامر أساسية

| اكتب في واتساب | الوظيفة |
|---|---|
| `.اوامر` أو `.menu` | القائمة العربية كاملة |
| `.وضع عام` / `.وضع خاص` | تمكين الأعضاء أو قصر الأوامر على المالك والمساعدين |
| `.منع_الروابط تشغيل` | حذف الروابط في المجموعة (البوت لازم يكون مشرف) |
| `.منع_الروابط تعيين تحذير` | تحديد إجراء المخالفة؛ القيم: `حذف` أو `طرد` أو `تحذير` |
| `.منع_الشتائم تشغيل` ثم `.منع_الشتائم add كلمة` | تفعيل قائمة كلمات تخصصها لكل مجموعة |
| `.ترحيب تشغيل` / `.ترحيب تعيين أهلًا {user}` | تفعيل رسالة ترحيب/تخصيصها |
| `.ملصق` بالرد على صورة/فيديو | صنع ملصق باسم Black X |
| `.ذكاء سؤالك` | رد من خدمة ذكاء اصطناعي خارجية بالعربي عند توفرها |
| `.نطق النص` | نطق النص عربيًا |
| `.ترجم Hello ar` | ترجمة نص للعربية |
| `.مالك` / `.اعدادات` | بيانات المالك / إعدادات البوت |

الأوامر الإدارية تتطلب صلاحيات المشرف للبوت ومرسل الأمر. أوامر المالك تتطلب الرقم المرتبط بالبوت أو `OWNER_NUMBER` أو مساعدًا موثوقًا في قائمة `.sudo`. خُذ موافقة أعضاء المجموعة قبل تفعيل الحفظ التلقائي للحالات أو مكافحة الحذف، والتزم بشروط واتساب وحقوق المحتوى.

## تشغيل Heroku

اتبع [docs/HEROKU_AR.md](docs/HEROKU_AR.md): تجهيز قاعدة Postgres، ضبط المتغيرات، تشغيل worker واحد، ربط الرقم مرة واحدة من السجلات، والتحقق بعد إعادة التشغيل. **لا توجد خطة مجانية دائمة لـ Heroku في هذا الإعداد.**

## فحص وملاحظات

```bash
npm run check     # فحص الصياغة وتحميل الوحدات
npm test          # اختبارات الأوامر العربية والصلاحيات والربط/التشفير دون اتصال واتساب
npm run cleanup   # تنظيف ملفات الوسائط المؤقتة فقط (لا يمس الجلسة)
```

ملاحظة أمنية: فحص `npm audit --omit=dev` ما زال يُظهر تحذيرات متوارثة من Baileys وبعض مكتبات التنزيل/TTS؛ تابع تحديثها ولا تشغّل البوت على رقم أساسي قبل تقييم المخاطر. أوامر الموسيقى والتنزيل وبعض توليد الصور تعتمد على خدمات طرف ثالث؛ قد تتوقف أو تطلب مفاتيح API وتحتاج تحديثًا لاحقًا. أوامر الطقس والأخبار تحتاج `OPENWEATHER_API_KEY` و`NEWS_API_KEY` من حساباتك. مشروع Baileys غير رسمي، وقد يتغير بروتوكول واتساب ويستلزم تحديث المكتبة. لم يُجرَ اختبار ربط حقيقي برقم واتساب أو نشر فعلي على Heroku من هذه البيئة.

للتخصيص: `settings.js` للهوية والمتغيرات، `lib/command-aliases.js` للأوامر العربية، `lib/arabic-strings.json` لترجمات الرسائل القديمة، `commands/help.js` للقائمة. **ما تشغّليش الأمر `.تحديث` من البوت لتغيير الكود**؛ هو الآن يعرض تعليمات آمنة ويمنع استبدال تعديلاتك بكود المشروع الأصلي.

### صمت المجموعات (خصوصية)

لمنع البوت من إرسال **أي رسالة** في مجموعة محددة، أرسل من رقم البوت المرتبط أو رقم المالك إلى **داخل المجموعة نفسها**: `.صمت تشغيل`. الأمر لا يرسل تأكيدًا للمجموعة؛ بعدها يتجاهل رسائلها وأحداث انضمام الأعضاء، ويمنع إرسال الرسائل إليها حتى من معالجات الأخطاء. كرر الأمر في أي مجموعة تريد إسكاتها. لإلغاء الصمت داخل نفس المجموعة أرسل `.صمت إيقاف` (أيضًا بدون تأكيد). تأكد من نجاح التغيير بتجربة `.اوامر` من حساب آخر بعد الانتظار؛ لا تستخدم مجموعة حساسة للاختبار قبل نشر الإصلاح. تحفظ القائمة في PostgreSQL إذا كان التطبيق يعمل على Heroku. **لإيقاف كل الرسائل فورًا قبل نشر الإصلاح:** `heroku ps:scale worker=0 -a اسم-تطبيقك`. لا تعيد تشغيل العامل قبل نشر الإصلاح والتأكد من إسكات الجروبات المطلوبة.
